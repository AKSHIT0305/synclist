# native/

Native widget code. It lives outside `android/` and `ios/` because those folders are generated by `expo prebuild` and must never be edited by hand. Custom Expo config plugins copy this code in at build time.

- `android-widget/` (**Phase 4**): a Kotlin + Jetpack Glance home-screen widget in three sizes, plus:
  - a configuration activity
  - a WorkManager fallback refresh
  - the checkbox action
- `ios-widget/` (**Phase 5**): a SwiftUI + WidgetKit extension with App Group storage and App Intents.

The app and the widgets share only a small JSON snapshot per list. The widget reads nothing else.
